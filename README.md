# I Should Have Listened

A gentle, mobile-friendly apology site starring Peach and Goma, with an interactive envelope and a letter. Built with plain HTML, CSS and JavaScript; no frameworks, backend, analytics, tracking, music, or forms. The page does not pressure its recipient to forgive or reply.

## Preview and hosting

Open index.html locally to preview. When satisfied, merge the feature branch and configure GitHub Pages in Settings → Pages → Deploy from a branch → main / root. The expected live address is:

https://wo0f27.github.io/please-forgive-me-my-love/

IMPORTANT: This repository is PUBLIC. The noindex meta tag is not a privacy control. Do not include identifying personal details, screenshots of private conversations or private photographs without consent.

## Customize

- Update the apology paragraphs in index.html to use your own voice before sharing.
- The promise section contains suggested commitments; keep only what you intend to follow through on.
- Change the design in the inline CSS of index.html.
- The temporary artwork is assets/peach-goma.webp, optimized from the image the user supplied in chat.

## Design principles

This is an apology, not a forgiveness request. No guilt-inducing countdowns, forgiveness buttons, automatic acceptance, hidden tracking, or forced animation. The site should accompany, not replace, real conversation and demonstrated change.
